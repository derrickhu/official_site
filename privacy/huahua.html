花花妙屋隐私政策

发布日期：2026年9月10日
生效日期：2026年9月10日
运营者：深圳幸运呱科技有限公司（以下简称「我们」）

本政策适用于我们运营的游戏《花花妙屋》（以下简称「本游戏」），包括但不限于微信小游戏、抖音小游戏、华为快游戏及后续上线的其他发行渠道。请在使用本游戏前阅读并理解本政策。如您不同意，请停止使用本游戏。

一、我们收集的信息

为提供游戏服务，我们可能收集如下信息：

  1. 账号信息。当您使用华为账号、微信、抖音等平台账号登录时，我们会获取平台提供的必要标识（如 OpenID、UnionID），用于登录、存档绑定与防作弊。
  2. 游戏数据。包括等级、关卡或经营进度、背包、装修与换装、任务与签到记录等，用于保存进度、同步云存档和提供客服支持。
  3. 设备与日志信息。包括设备型号、操作系统版本、网络类型、崩溃日志、性能数据，用于保障运行稳定与排查故障。
  4. 广告标识。在您同意个性化广告的前提下，可能使用广告标识符（如 OAID）用于广告投放与效果统计。您可在系统设置中限制广告跟踪。
  5. 您主动提供的信息。如您通过客服、邮箱或反馈入口联系我们时提供的联系方式与问题描述。

我们不会主动收集您的身份证号、银行卡号、精确地理位置、通讯录、短信或通话记录。如后续功能确需收集，我们将另行告知并征得同意。

二、我们如何使用信息

  1. 提供、维护和改进本游戏的核心功能，包括合成经营、花店装修、任务与活动。
  2. 保存与同步游戏进度，识别账号，防止作弊与滥用。
  3. 进行匿名或去标识化的数据分析，用于优化体验与内容。
  4. 在本游戏内展示广告（激励视频、横幅或原生广告等），并为广告结算提供必要统计。
  5. 响应您的咨询、投诉与个人信息相关请求。
  6. 履行法律法规、监管要求或保护用户与我们的合法权益。

三、我们如何共享、转让、公开披露信息

我们不会出售您的个人信息。仅在以下情形共享：

  1. 发行与登录平台。微信、抖音、华为等平台按其规则处理账号登录、支付（如开通）与安全能力。
  2. 云服务。腾讯云开发等服务商为存档、静态资源与数据分析提供技术支持。
  3. 广告服务。在华为渠道可能接入鲸鸿动能等广告服务；在微信、抖音渠道可能使用对应平台广告能力。相关处理遵循该服务商的隐私政策。
  4. 法定情形。根据法律法规、诉讼、仲裁或行政机关依法提出的要求。

如发生合并、分立、收购，我们会要求承继方继续受本政策约束，否则将重新征求您的授权。

四、第三方服务与 SDK

本游戏可能集成以下类型的第三方服务，具体以您使用的渠道版本为准：

  • 平台账号登录与基础能力（微信 / 抖音 / 华为）
  • 广告变现服务（如鲸鸿动能、平台流量主）
  • 云存档、云函数与数据分析（腾讯云开发）

第三方可能通过其 SDK 收集设备信息、网络信息或广告标识。我们要求合作方依法处理个人信息，并仅开放实现功能所必要的数据。您可在对应平台或系统设置中管理广告与授权。

五、我们如何存储和保护信息

我们在中华人民共和国境内存储收集的个人信息。法律法规另有规定或经您另行同意的除外。我们采取合理的技术与管理措施保护数据安全，包括访问控制、传输加密与最小授权。互联网环境并非绝对安全，请妥善保管账号。

在实现收集目的所需的最短期限内保存个人信息；超出期限后将删除或匿名化处理，法律法规另有规定的除外。

六、您的权利

在符合法律法规的前提下，您有权：

  1. 查阅、复制我们持有的您的个人信息；
  2. 更正、补充不准确或不完整的信息；
  3. 删除依法可删除的信息，或撤回同意（撤回不影响此前基于同意的处理）；
  4. 注销账号或申请删除云存档（注销后可能无法恢复游戏进度）；
  5. 获取个人信息处理说明，或对处理活动提出限制、反对。

请通过本政策「如何联系我们」所述方式提出请求。我们将在核实身份后，原则上于十五个工作日内答复。

七、未成年人保护

本游戏主要面向一般用户。如您是未满十四周岁的未成年人，请在监护人陪同下阅读本政策，并在监护人同意后使用。我们不会主动向不满十四周岁的儿童收集个人敏感信息。监护人如需查询、更正或删除相关信息，请联系我们。

请合理安排游戏时间。我们将依法配合防沉迷、适龄提示等要求。

八、个性化广告

本游戏可能通过展示广告获得收入。如使用广告标识进行个性化推荐，我们将在隐私政策或游戏内告知，并尽量提供关闭个性化推荐的路径。关闭后，广告数量不一定减少，但相关程度可能下降。

九、本政策的更新

我们可能适时修订本政策。更新后将在本页面公布，并更新「生效日期」。重大变更时，我们会通过游戏内提示或其他合理方式通知您。您继续使用本游戏，即表示同意更新后的政策。
